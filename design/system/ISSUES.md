# Inconsistencies in Quire's design system

Generated by `build.py` from `issues.json`. Paths are under `desktop/src` unless they start with `docs/`, `android` or `design/`.
`checked`: the lines were re-read against the code. `reported`: from a map only, read the lines before acting.

## Sizing

### SZ-01 · Text buttons come in four heights

Severity high, checked.

- In a row: **26** (`ui/settings.rs:497, :632, :660; ui/settings_mcp.rs:228; ui/reader.rs:385; ui/editor.rs:188`)
- Settings row: **30** (`ui/settings.rs:457, :483; ui/settings_mcp.rs:246`)
- Dialog: **32** (`ui/lock.rs:173, :244; ui/trash.rs:235; ui/settings_sync.rs:361; ui/settings_mcp.rs:106`)
- First note: **34** (`ui/editor.rs:1502`)

Why: outline_button takes its height from each caller, so nothing holds the set together. The prototype already had 30, 32 and 34 (design/Quire.dc.html L347, L434, L220).

Proposal: Two heights: 32 for a dialog's or page's action, 26 for a button inside a row. Move 30 to 32 and 34 to 32. Make the height a named size, not a number at the call.

Decision: Settled: two button heights in ui/components/button.rs (32 dialog, 28 panel/row via .sm()).

### SZ-02 · Icon buttons are 28 in panels and 24 in bars, with no rule written down

Severity high, checked.

- icon_button default: **28 × 28** (`ui/widgets.rs:210; sidebar top bar and footer; Settings close ui/settings.rs:61; toolbar toggles ui/editor.rs:705`)
- Bars and mini-bars: **24 × 24** (`ui/titlebar.rs:15; ui/widgets.rs:125; ui/reader.rs:100, :391; ui/editor.rs:863`)

Why: The title bar overrides icon_button's 28 with .size(24, 24). Two dialogs close with different buttons: Settings 28, help 24.

Proposal: Keep both, as two named sizes with a rule: 28 where the button stands alone in a panel or dialog header, 24 inside a bar. Give Settings and help the same close button.

Decision: Settled: named IconButtonSize (Bar 24, Panel 28, Toolbar 28); Help and Settings close buttons both use Panel 28.
